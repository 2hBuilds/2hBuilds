# 2hBuilds

RuneLite plugins for Old School RuneScape. To install one, open RuneLite, click the Plugin Hub (plug icon), search the name and click Install.

## 2h Bank Portfolio Tracker

See what your bank is worth and how it moves.

- Price changes for every item over 1, 7, 30, 90 or 180 days, in gp and %
- Net Worth History: your bank's total saved once a day, as a chart
- Counts your inventory, worn gear and Grand Exchange offers
- Live prices for items that trade a lot

[Plugin Hub page](https://runelite.net/plugin-hub/show/bank-portfolio-tracker) · [Source and issues](https://github.com/2hBuilds/bank-portfolio-tracker)
